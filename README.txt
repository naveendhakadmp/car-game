NAVEEN DRIVING CAR - UPDATED

IMPORTANT: Open THIS extracted folder itself in VS Code, then right-click index.html and choose Open with Live Server.
If Live Server shows a directory listing, click index.html or stop Live Server and open this folder (not its parent folder) in VS Code.

Controls:
W / Up Arrow = accelerate
S / Down Arrow = brake
A / Left Arrow = steer left
D / Right Arrow = steer right
1 = cockpit dashboard, 2 = hood view, 3 = outside view
E = engine toggle

The road and road markings recycle as you drive. Each level is about 1200 in-game distance units. Music is bundled in assets/Main_Nikla_Gaddi_Leke.mp3; press MUSIC ON after entering the car.
Internet is required for Three.js from the CDN.
